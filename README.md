## About

I'm a frontend engineer with 7+ years of experience building B2B web applications, micro-frontend platforms and design systems. I drive frontend architecture through ADRs, work with designers to turn Figma into responsive, accessible UI, and run code review and technical hiring. I also go fullstack when the product needs it, and I've shipped production LLM features with LangChain and the Model Context Protocol (MCP).

## Selected impact

- **Frontend Builder at Censhare:** designed a modular platform for assembling customer-specific UIs from shared components. It runs at 10+ enterprise customers, and new custom UIs now take weeks instead of months.
- **Micro-frontend runtime:** set up Import Maps so 30+ micro-frontends share a single React/vendor runtime, and bundle size stayed flat as new frontends were added.
- **MCP server:** built a server that exposes asset management, metadata editing and publishing to LLM agents: 35 permission-scoped tools, live at 4 customers.
- **Architecture:** wrote the ADR for a five-layer feature architecture, now the standard in 13 product modules.
- **Accessibility:** made WCAG 2.2 AA and BFSG compliance part of code review and the Definition of Done, with Playwright accessibility checks in CI.
- **Quality at scale:** Vitest and Playwright pipelines gated every merge request across 200+ releases and cut escaped production defects by 20%. Earlier, I raised test coverage from 10% to 80% at FYEO.
- **Public-sector scale:** delivered platforms serving 2M+ citizens and a vehicle registration engine handling 1.5M+ entries a year, with page loads about 40% faster after moving to Next.js SSR/SSG.
